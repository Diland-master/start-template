# Система вёрстки на шаблоне `_start-template-vite`

Это стартовый шаблон для вёрстки сайтов. Когда присылают дизайн (ссылка на Figma, скриншоты, PDF, картинки, описание), сайт верстается **копией этого шаблона** строго по правилам из `docs/`.

Эталон, на котором выведены правила: проект `_stream-vibe-9.1` (готовая вёрстка на этом шаблоне).

## С чего начинать

1. Прочитать документы в порядке номеров:
   - [`docs/01-workflow.md`](docs/01-workflow.md) — процесс: от дизайна до сданной вёрстки.
   - [`docs/02-architecture.md`](docs/02-architecture.md) — стек, папки, именование, страницы.
   - [`docs/03-styles.md`](docs/03-styles.md) — SCSS: токены, `fluid()`, брейкпоинты, БЭМ.
   - [`docs/04-components.md`](docs/04-components.md) — как писать JSX-компоненты и секции.
   - [`docs/05-js-modules.md`](docs/05-js-modules.md) — интерактив: модули на `data-js-*`.
   - [`docs/06-a11y-assets.md`](docs/06-a11y-assets.md) — доступность, картинки, иконки, шрифты.
   - [`docs/07-checklist.md`](docs/07-checklist.md) — чек-лист перед сдачей.
2. Готовые компоненты брать из [`_library/`](_library/README.md) — **копировать в проект только то, что нужно по дизайну**, и перекрашивать под токены нового дизайна.

## Ключевые правила (кратко)

- Стек: **Minista 3** (статическая генерация из JSX) + **SCSS** + Vite. Никакого React-рантайма в браузере: JSX — только шаблонизатор, интерактив пишется на ванильном JS в `src/modules`.
- Структура: `pages/` → `layouts/` → `sections/` → `components/`. Каждый компонент — папка `Name/` с `Name.jsx`, `Name.scss`, `index.js`.
- CSS: **БЭМ** (`block__element--modifier`), состояния — `is-*`, никакого CSS Modules и Tailwind.
- Размеры: **`fluid(max, min)`** и **`fluid-to-laptop(max, min)`** вместо фиксированных px там, где значение в дизайне меняется между экранами.
- Медиазапросы: только миксины `laptop` / `tablet` / `mobile` / `mobile-s` (и `*-above`), ховер — только `@include hover`.
- Цвета, радиусы, бордеры — только через CSS-переменные из `variables.scss`, имена палитры берутся из дизайна.
- Код: **табы**, без `;`, одинарные кавычки (prettier в `package.json`, `.editorconfig`).
- Семантика и доступность обязательны: `aria-labelledby` у секций, один `h1` на страницу, `visually-hidden` для скрытых заголовков, клавиатурная навигация в интерактиве.

## Команды

```bash
npm i          # установка
npm start      # dev-сервер
npm run build  # сборка в dist/ (px → rem включается только здесь)
npm run preview
```
