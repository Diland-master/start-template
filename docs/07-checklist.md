# 07. Чек-лист перед сдачей

## Соответствие дизайну
- [ ] Все страницы и секции из дизайна свёрстаны, порядок блоков совпадает.
- [ ] Отступы, размеры шрифтов, радиусы и цвета совпадают на desktop, laptop и mobile.
- [ ] Проверены ширины 1920, 1440, 1280, 1024, 768, 480, 390, 360: нет горизонтального скролла и наложений.
- [ ] Hover, active, focus и disabled есть у всех интерактивных элементов.
- [ ] Длинные тексты и переносы не ломают карточки.

## Код
- [ ] Компонент = папка `Name/` с `Name.jsx`, `Name.scss` (если есть стили) и `index.js`.
- [ ] Только БЭМ-классы, состояния `is-*`, в JS нет поиска по классам.
- [ ] Нет hex-цветов вне `variables.scss` (кроме прозрачных стопов градиентов).
- [ ] Нет ручных `@media`: только миксины. Ховер только через `@include hover`.
- [ ] Значения, которые меняются между макетами, заданы через `fluid` / `fluid-to-laptop`.
- [ ] Отступы табами, без `;`, одинарные кавычки. Импорты через `@/`.
- [ ] Данные списков вынесены в массивы. Нет копипасты разметки карточек.
- [ ] Компоненты из `_library/` перекрашены под токены нового проекта: не осталось `--color-red-45` и других имён, которых нет в `variables.scss`.
- [ ] Все модули подключены в `main.js`, в консоли нет ошибок ни на одной странице.

## Доступность
- [ ] Один `h1` на страницу, у секций есть `aria-labelledby`.
- [ ] У кнопок-иконок есть `aria-label`, у картинок — `alt`, у `<img>` указаны `width` / `height`.
- [ ] Всё интерактивное работает с клавиатуры, фокус виден.

## Сборка
- [ ] `npm run build` проходит без ошибок и предупреждений Sass.
- [ ] В `dist/` открываются все страницы, картинки, шрифты и иконки на месте.
- [ ] Заменены `site.js`, `site.webmanifest`, фавиконки и `<title>`.
